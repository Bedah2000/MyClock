# Lernuhr – Version 13

Fertige Dateien zur direkten Verwendung. Die ZIP-Dateien enthalten jeweils ein vollständiges SCORM-1.2-Paket für mebis. Zum Hochladen in mebis die ZIP-Datei unverändert lassen.

- [HTML-Datei herunterladen](lernuhr-13.html?raw=true) – eigenständige Offline-Version; im Browser öffnen.
- [SCORM: vollständige Lernuhr](lernuhr-scorm.zip?raw=true) – startet im Bereich Lernuhr, mit Quiz und Sonne & Mond.
- [SCORM: Quiz volle Stunden](lernuhr-quiz-volle-stunden.zip?raw=true)
- [SCORM: Quiz halbe Stunden](lernuhr-quiz-halbe-stunden.zip?raw=true)
- [SCORM: Quiz Viertelstunden](lernuhr-quiz-viertelstunden.zip?raw=true)
- [SCORM: Quiz 5 Minuten](lernuhr-quiz-5-minuten.zip?raw=true)
- [SCORM: Quiz alle Minuten](lernuhr-quiz-alle-minuten.zip?raw=true)

Die Quiz-Pakete starten direkt im Quiz mit der jeweiligen Lernstufe. Die Hilfen werden dadurch nicht automatisch umgeschaltet.

Die Dateien stammen aus demselben Build wie die visuell geprüfte HTML-Fassung. [Prüfbericht](../pruefbericht-freigabe.md).
